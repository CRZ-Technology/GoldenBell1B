# GoldenBell1B

CRZ Technoloy released GolenBell1B board which is based on AMD Spartan-7 FPGA(XC7S6FTGB196).

Directory

           - GoldenBell1B_CPU_test_platform_manual - documents about GoldenBell1B

           - peripheral_test_code - LED / KEY / FND / BUZZER / DIP SWITCH / UART test verilog code

# Features

-	Xilinx Spartan-7 XC7S6-FTGB196 FPGA
-	FTDI FT2232H USB-JTAG-Serial IC
-	SPI program flash (16Mbit)
-	14pin JTAG connector
-	4 digit 7 segment
-	16 LED indicators
-	5 Function keys with 5 LED indicators
-	6 position DIP switch
-	1 Buzzer
-	1 Reset Key
-	Interface Connectors
-	2x 8P Connectors
-	40P Connector
-	DC-JACK 5V
